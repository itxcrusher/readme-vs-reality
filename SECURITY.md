# Sensitive Findings and Corrections

This repository reports a review of the author's own prototype. It publishes no third-party findings.

If you believe a statement here is wrong, or that something published creates a risk, do not post exploit details, credentials, or private data in a public issue.

Use GitHub private vulnerability reporting if it is enabled; otherwise contact the author through the verified contact method on the `itxcrusher` GitHub profile.

Reports should include the affected statement, supporting evidence, and the minimum detail needed to understand the concern safely.

This project reports historical research. A correction may change confidence, wording, or scope without changing the underlying private evidence record.
